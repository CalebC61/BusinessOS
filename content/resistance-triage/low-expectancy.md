# Low Expectancy

**Signal:** prediction language — the user believes the action won't succeed before trying it.

**Routed sequence:** `04-cognitive-restructuring.md` (thought record on the specific failure prediction) → if a confidence rating is captured, chain into `05-behavioral-experiments.md` (schedule a real test of the prediction, pre-registered confidence checked against the outcome).

**Delivery:** Coaching chat (AGENTS.md Role 3) presents the thought record inline; it does not proceed to the behavioral experiment without the user completing the thought record first — the sequence is enforced, not optional-skip.
