## Purpose

Two-part card. **Values clarification** runs once at onboarding (PRD §8.1 card-sort, pick 3) and its output (`value_link`) is displayed on every directive going forward. **Defusion** is the micro-exercise routed from the Resistance Triage `low_value` branch (`content/resistance-triage/low-value.md`) when a skip is driven by meaning language ("who cares / doesn't matter").

## Script (personalization slots)

Onboarding card-sort: user picks 3 from a fixed value deck (e.g. security, craftsmanship, family, independence, growth) — no personalization slots, selection only.

Defusion micro-exercise:
> Notice you're having the thought "`{{fused_thought}}}`." That's a thought, not a fact. This action connects to `{{value_link}}` — does doing it move you toward that, regardless of how today's thought reads?

## Contraindications

Defusion is not a talking-someone-out-of-a-feeling exercise — if `{{value_link}}` genuinely doesn't apply to the skipped action (a values mismatch, not a distortion), the card should surface that as a real signal for the weekly review, not force a link that isn't there.

## Evidence reference

Hayes, S. C., et al. — Acceptance and Commitment Therapy (ACT) process research; values-linked action sustaining engagement where motivational content decays.
