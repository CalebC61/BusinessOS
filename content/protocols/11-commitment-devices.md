## Purpose

Optional layer, not part of the core daily loop — offered from the Resistance Triage `impulsiveness` branch (`content/resistance-triage/impulsiveness.md`) as an environment-design prescription when distraction is the recurring block. Two mechanisms: pre-commitment stakes, and pairing a dreaded action with a liked context (temptation bundling).

## Script (personalization slots)

> **Pre-commitment:** if `{{action}}` isn't done by `{{deadline}}`, `{{stake}}` happens.
> **Temptation bundling:** only allow yourself `{{liked_activity}}` while/immediately after doing `{{dreaded_action}}`.

Both are opt-in per user, never defaulted on — this card is explicitly the "optional layer" per PRD §6 row 11, not a mandatory part of the loop.

## Contraindications

Stakes must be proportionate and non-punitive in a way that damages the relationship (e.g., financial stakes should be small and user-chosen, never set by the app to an amount the user didn't pick) — this is a self-chosen commitment device, not an app-imposed penalty.

Milkman, K. L., et al. — behavioral economics of self-control; commitment devices and temptation bundling.
